## Descripción
Web crawler que extrae las primeras 30 entradas de Hacker News con filtros inteligentes.

## Tecnologías
- **Frontend**: Angular 17 + CSS puro
- **Backend**: Spring Boot 3 + Jsoup
- **Base de datos**: H2
- **Container**: Docker & Docker Compose

## Estructura

hacker-news-project/
├── frontend/ # Angular application
└── backend/ # Spring Boot application
└── base/ # H2


## Requisitos
- Node.js 18+
- Java 17+
- Docker (opcional)
